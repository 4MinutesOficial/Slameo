Política de Privacidade

Última atualização: 05 de setembro de 2026.

Este aplicativo é de uso pessoal e tem como única finalidade acessar boards e pins da própria conta Pinterest do desenvolvedor, com o objetivo de exibir automaticamente essas imagens em um servidor privado do Discord.

Quais dados são acessados

O aplicativo acessa, através da API oficial do Pinterest, apenas boards e pins pertencentes à conta que autorizou o aplicativo. Nenhum dado de outros usuários do Pinterest é coletado, acessado ou armazenado.

Armazenamento de dados

O aplicativo armazena localmente, de forma segura, apenas o token de acesso necessário para autenticação com a API do Pinterest. Nenhuma imagem, pin ou informação pessoal é redistribuída publicamente na web ou compartilhada com terceiros.

Compartilhamento de dados

Nenhum dado é vendido, alugado ou compartilhado com terceiros. O conteúdo obtido é exibido apenas dentro de um servidor privado do Discord, com acesso restrito aos seus membros.

Contato

Dúvidas sobre esta política podem ser enviadas ao desenvolvedor responsável pelo aplicativo através do servidor do Discord onde o aplicativo é utilizado.

Termos de Uso

Uso permitido

Este aplicativo destina-se exclusivamente ao uso pessoal do desenvolvedor, para fins de automação de conteúdo em um servidor privado do Discord. Não é disponibilizado publicamente para uso por terceiros.

Isenção de responsabilidade

O aplicativo é fornecido "como está", sem garantias de disponibilidade contínua. O desenvolvedor não se responsabiliza por indisponibilidades da API do Pinterest ou do Discord que possam afetar o funcionamento do aplicativo.

Alterações

Esta política e estes termos podem ser atualizados a qualquer momento, sem aviso prévio, para refletir mudanças no funcionamento do aplicativo.
